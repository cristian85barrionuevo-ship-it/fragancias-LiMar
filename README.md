# Fragancias LiMar

Catálogo de perfumería con carrito, pedidos contra entrega y administración privada.

## Base de datos

El proyecto usa Supabase. La migración inicial está en `supabase/schema.sql`.

## Próximos pasos

- Conectar la interfaz con Supabase mediante variables de entorno.
- Activar autenticación para el panel privado.
- Guardar productos, stock y pedidos.
- Enviar el resumen del pedido a WhatsApp comercial.

Nunca subir claves secretas al repositorio. Usar variables de entorno para las credenciales de Supabase.
